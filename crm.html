Подключение к Firebase

Вставь конфиг своего Firebase-проекта (тот же, что использует Telegram-бот — Firestore Native, коллекции listings / users / friend_profiles / reviews / subscriptions / config). Вход не нужен: CRM работает по открытым правилам Firestore. Конфиг сохраняется только в этом браузере.

Firebase Console → ⚙ Project settings → раздел «Your apps» → Config. Можно вставить и как объект JS (apiKey: "..."), CRM сама распарсит.
